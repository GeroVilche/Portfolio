Lo que construí

El Oreja Details

En producción

Sitio para un negocio de detailing de autos con un sistema de turnos online: el cliente elige servicio, día y horario libre, y el turno queda cargado en el Google Calendar del negocio. Cada reserva genera un link personal para ver o cancelar el turno.

Lo que resolví

  • API REST con Node.js y Express que calcula la disponibilidad real contra Google Calendar, con margen entre turnos y horarios por día (incluye horario cortado y días cerrados).
  • Configuración del negocio en un solo archivo, que el frontend lee desde la API: el sistema se adapta a otro negocio sin tocar código.
  • Seguridad: validación de todos los datos en el backend, CORS restringido, límite de pedidos por IP y prevención de XSS en el frontend.
  • Fechas y horas en hora de Argentina sin depender de la zona horaria del servidor.
  • Deploy con frontend en GitHub Pages y backend en Render, con variables de entorno y trabajo por ramas y Pull Requests.
